# v0.1.1 release plan

Infrastructure and distribution release:

- GitHub Pages project site
- optional macOS Intel workflow
- upload Intel package to an existing release
- itch.io page text, tags and Butler channels

## GitHub Pages

In repository settings, select:

**Settings → Pages → Build and deployment → Source: GitHub Actions**

## Intel Mac

Run **Build optional macOS Intel package**, enter the existing release tag and
leave upload enabled. The build is attached to that release when a runner is
available.

## itch.io

Create a Downloadable project. Paste `release/itch/PAGE.md`, add the tags from
`release/itch/TAGS.txt`, download release ZIPs into `dist/`, then run:

```bash
./scripts/publish-itch.sh ACCOUNT/retro-palette-converter 0.1.1
```
