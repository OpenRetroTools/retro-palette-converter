# Changes

- Adds Atkinson error-diffusion dithering.
- Adds Bayer 2×2, Bayer 4×4, and Bayer 8×8 ordered dithering.
- Registers all new algorithms so CLI and GUI discover them automatically.
- Extends `DitherMode` compatibility values.
- Adds deterministic, palette-safety, periodic-pattern, and alpha-preservation tests.
