# M2.2c — Advanced error diffusion

Adds Sierra Lite, Sierra, Burkes, Stucki, and Jarvis–Judice–Ninke dithering through the shared registry.

Apply by extracting the overlay into the repository root, then run:

```bash
chmod +x .delivery/M2.2c/APPLY.sh .delivery/M2.2c/VERIFY.sh
./.delivery/M2.2c/APPLY.sh
./.delivery/M2.2c/VERIFY.sh
```
